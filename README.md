**RAGE//SOCIAL** is a chaotic, satirical social media experience designed to answer one important question:

**How long can a human being tolerate the internet before losing their last remaining brain cell?**

Forget user-friendly interfaces. Forget frictionless experiences. Forget respecting your time.

Here, the password requirements are unreasonable, the CAPTCHA doesn't trust you, the scrollbar has an ego, and the Follow button has commitment issues.

Welcome home. 💀

---

## 📸 The Experience

RAGE//SOCIAL is a deliberately infuriating, comedy-driven social media simulation featuring ridiculous UI interactions, fake notifications, absurd validation rules, and features that exist for absolutely no productive reason.

Every interaction is a new opportunity to question your life choices.

**Two pages. Zero backend. Infinite emotional damage.**

## 🛠️ Tech Stack

RAGE//SOCIAL is designed to run directly in your browser.

- **HTML5** — Structure and content.
- **CSS3** — Styling, animations, chaotic layouts, and visual effects.
- **Vanilla JavaScript** — Validation, interactions, popups, themes, and questionable decisions.
- **Web Audio API** — Optional browser-generated audio effects.
- **SVG** — Emergency corn deployment when the image asset is missing.

### The best part?

- No backend.
- No build step.
- No package installation.
- No database.
- No reason to put yourself through this.

## 🚀 Installation

### 1. Clone the repository

```bash
git clone <YOUR_REPOSITORY_URL>
```

### 2. Enter the project directory

```bash
cd RAGE-SOCIAL
```

### 3. Open the website

Open `index.html` directly in your browser.

## 🔒 Privacy & Security

RAGE//SOCIAL is intended as a local, frontend-only demo.

- Demo credentials are not intended for real accounts.
- The project is designed without a backend or database.
- No data is intentionally transmitted or persisted by the demo as described.
- Do not enter real passwords or sensitive personal information.
- Browser features, extensions, or modifications may affect behavior.

**Important:** These are the project's intended characteristics, not an independent security audit. Review the JavaScript and any third-party resources before making stronger privacy claims.

This is a satire project, not a production-ready social network.
